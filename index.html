Opening it the first time

Blobline isn't code-signed yet, so your computer asks before the first launch. This goes away once it's signed.

On a Mac

  1. Open the .dmg and drag Blobline into Applications.
  2. Open Blobline. When macOS says it can't verify it, click Done.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway next to "Blobline was blocked".
  4. Open Blobline again and choose Open.

On Windows

  1. Run the installer.
  2. If Windows says it protected your PC, click More info, then Run anyway.
  3. The first start can take a minute while Windows checks the new program.
